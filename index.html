Cómo se juega

  1. Lee las pistas que aparecen sobre un compañero/a (pulsa «Ver pista» para descubrir más).
  2. Adivina quién es eligiendo entre las opciones.
  3. Cuantas menos pistas necesites, más puntos consigues.
  4. Al terminar, el juego te empareja con alguien para tomar un café. ¡Ese es el verdadero objetivo!
